# Forkies Bot

Стартовый Telegram-бот на Aiogram3 для организации ужинов с незнакомцами, интегрированный с MiniApp "Аллора Клаб".

## Установка и запуск

1. Установите зависимости: `pip install -r requirements.txt`
2. Получите токен бота у @BotFather в Telegram.
3. Вставьте токен в `bot.py` (BOT_TOKEN).
4. Разверните MiniApp на Vercel и вставьте URL в `bot.py` (MINIAPP_URL).
5. Запустите бота: `python bot.py`

## Функционал

- Приветствие с описанием сервиса.
- Открытие MiniApp для заполнения анкеты.
- Симуляция поиска компании и бронирования ресторана.
- Подтверждение/отмена встречи.
