# Antre Club — Networking Bot App

**Платформа для организации сетевых встреч и знакомств** — Telegram бот с встроенным MiniApp (Next.js), FastAPI backend и интеграцией системы платежей ЮKassa.

## 🚀 Архитектура

`MiniApp (Next.js на Vercel)` ↔ `FastAPI (Python на VPS)` ↔ `Telegram Bot (Aiogram)` ↔ `PostgreSQL`

### Технологический стек
*   **Frontend**: Next.js 15 (App Router), Tailwind CSS, Framer Motion.
*   **Backend**: FastAPI, Aiogram 3.x.
*   **База данных**: PostgreSQL + SQLAlchemy (Async).
*   **Платежи**: ЮKassa API (Webhooks).

## 🛠️ Основные функции

### 📱 Для пользователя
*   **Умный профиль**: Детальный онбординг для подбора идеальной компании.
*   **Афиша**: Просмотр и бронирование предстоящих ужинов в один клик.
*   **Мои контакты**: Просмотр анкет участников прошедших встреч, сгруппированных по мероприятиям.
*   **Командный дух**: Специальные метки для участников вашей команды на ужине.

### 👮 Для администратора
*   **Управление слотами**: Гибкое создание и редактирование мероприятий.
*   **Smart Grouping**: Автоматическое и ручное распределение участников по командам.
*   **Рассылки**: Уведомление всех пользователей о новых событиях.
*   **Dashboard**: Наглядная статистика по бронированиям и пользователям.

## 📖 Инструкции

### 👤 Пользователю
1.  **Старт**: Откройте бота и нажмите `/start`.
2.  **Анкета**: Заполните профиль (это поможет алгоритму подобрать вам компанию).
3.  **Выбор**: В разделе **Афиша** выберите подходящий ужин по дате и локации.
4.  **Оплата**: Оплатите оргсбор через ЮKassa прямо в приложении.
5.  **Встреча**: За 24 часа до ужина бот пришлет адрес ресторана. Приходите и наслаждайтесь общением!

### 🔑 Администратору
1.  **Вход**: Введите команду `/admin` в боте для перехода в панель управления.
2.  **События**: В меню **Мероприятия** создайте новый слот (дата, время, ресторан).
3.  **Группы**: После того как места заполнятся, перейдите в **Группы** и используйте "Авто-разбиение" или создайте команды вручную.
4.  **Связь**: Используйте раздел **Рассылка**, чтобы пригласить пользователей на новые встречи.

## 🔧 Установка и запуск (Разработка)

### Требования
*   Python 3.12+
*   Node.js 18+
*   PostgreSQL

### Быстрый старт
1.  **Клонирование**: `git clone <repo_url>`
2.  **Backend**:
    *   `cd bot`
    *   Настройте `.env` (см. `.env.example`).
    *   `pip install -r requirements.txt`
    *   Запустите скрипт управления: `./start_services.sh`
3.  **Frontend**:
    *   `npm install`
    *   `npm run dev`

## 🔒 Безопасность
*   **JWT**: Защищенная авторизация между MiniApp и Backend.
*   **Middleware**: Проверка прав администратора для всех чувствительных операций.
