# Orchids Networking Bot App

Этот проект представляет собой Telegram бота для нетворкинга с встроенным miniApp Telegram приложением. Бот помогает организовывать встречи и знакомства между людьми (вдохновлено Allora).

## Структура проекта

- `src/` - Frontend приложение на Next.js (miniApp)
- `bot/` - Backend Telegram бот на Python с использованием Aiogram3
- `public/` - Статические файлы (изображения и т.д.)

## Функционал

### Mini App
- **Онбординг**: 4 шага с визуализацией процесса.
- **Анкетирование**: Сбор данных о пользователе (имя, возраст, пол, статус отношений, дети, профессия, цели, интересы, уровень комфорта, частота общения, формат коммуникации, сценарий вечера, социальные ссылки, фото, "о себе").
- **Выбор города**: Фильтрация мероприятий.
- **Бронирование**: Просмотр доступных слотов, оплата через ЮKassa (симуляция), уведомления администратору.
- **Профиль**: Просмотр данных, редактирование, мои бронирования, контакты.

### Telegram Bot
- Приветствие и открытие Mini App.
- Симуляция подбора компании и бронирования.
- Уведомления о покупках.

## Установка и запуск

### Требования

- Node.js 18+ (для frontend)
- Python 3.8+ (для бота)
- Bun (рекомендуется для управления зависимостями)

### Frontend (miniApp)

1. Установите зависимости:
   ```bash
   bun install
   ```

2. Запустите сервер разработки:
   ```bash
   bun dev
   ```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### Backend (Telegram бот)

1. Перейдите в папку `bot/`:
   ```bash
   cd bot
   ```

2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```

3. Активируйте виртуальное окружение:
   - Windows: `venv\Scripts\activate`
   - Linux/Mac: `source venv/bin/activate`

4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. Настройте переменные окружения (создайте `.env` файл на основе примера).

6. Запустите бота:
   ```bash
   python bot.py
   ```

## Развертывание

### Frontend (Mini App)
- Разверните на Vercel или другом хостинге для Next.js.
- Настройте переменные окружения для интеграции с ботом.

### Backend (Telegram Bot)
- Бот должен работать на сервере с постоянным интернетом (например, Railway, Heroku или VPS).
- Настройте webhook или polling для Telegram API.

## Требования к изображениям

Все изображения хранятся локально в папке `public/images/`.

### Структура хранения
```
public/
  images/
    onboarding/
      step-1.png  - Шаг 1: "РАССКАЖИ О СЕБЕ"
      step-2.png  - Шаг 2: "ПОДБИРАЕМ КОМПАНИЮ"
      step-3.png  - Шаг 3: "МЫ ВСЁ ОРГАНИЗУЕМ"
      step-4.png  - Шаг 4: "ДЕНЬ X"
```

### Добавление изображений
1. Подготовьте изображения в формате PNG (или JPG).
2. Разместите их в папке `public/images/onboarding/`.
3. Назовите файлы согласно схеме: `step-1.png`, `step-2.png`, и т.д.
4. Изображения будут автоматически подхвачены приложением.

### Требования к изображениям
- **Формат**: JPG или PNG
- **Ориентация**: Портретная (вертикальная)
- **Рекомендуемое разрешение**: минимум 800x1200px
- **Оптимизация**: Рекомендуется оптимизировать для веба (можно использовать TinyPNG, ImageOptim и т.д.)

### Использование в коде
Пути к изображениям определены в `src/lib/images.ts`:
```typescript
import { IMAGE_PATHS } from "@/lib/images";

// Использование
const imagePath = IMAGE_PATHS.onboarding.step1; // "/images/onboarding/step-1.png"
```

### Примечания для Telegram MiniApp
- Все изображения должны быть оптимизированы для быстрой загрузки.
- Рекомендуется использовать формат JPG для фотографий.
- Размер файлов должен быть минимальным без потери качества.
