# Руководство по работе с изображениями

## Структура хранения

Все изображения хранятся локально в папке `public/images/`:

```
public/
  images/
    onboarding/
      step-1.png  - Шаг 1: "РАССКАЖИ О СЕБЕ"
      step-2.png  - Шаг 2: "ПОДБИРАЕМ КОМПАНИЮ"
      step-3.png  - Шаг 3: "МЫ ВСЁ ОРГАНИЗУЕМ"
      step-4.png  - Шаг 4: "ДЕНЬ X"
```

## Добавление изображений

1. Подготовьте изображения в формате PNG (или JPG)
2. Разместите их в папке `public/images/onboarding/`
3. Назовите файлы согласно схеме: `step-1.png`, `step-2.png`, и т.д.
4. Изображения будут автоматически подхвачены приложением

## Требования к изображениям

- **Формат**: JPG или PNG
- **Ориентация**: Портретная (вертикальная)
- **Рекомендуемое разрешение**: минимум 800x1200px
- **Оптимизация**: Рекомендуется оптимизировать для веба (можно использовать TinyPNG, ImageOptim и т.д.)

## Использование в коде

Пути к изображениям определены в `src/lib/images.ts`:

```typescript
import { IMAGE_PATHS } from "@/lib/images";

// Использование
const imagePath = IMAGE_PATHS.onboarding.step1; // "/images/onboarding/step-1.png"
```

## Примечания для Telegram MiniApp

- Все изображения должны быть оптимизированы для быстрой загрузки
- Рекомендуется использовать формат JPG для фотографий
- Размер файлов должен быть минимальным без потери качества
