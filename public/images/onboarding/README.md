# Изображения для онбординга

Эта папка содержит изображения для экранов онбординга.

## Требуемые файлы

Добавьте следующие изображения в эту папку:

- **step-1.png** - Изображение для первого шага "РАССКАЖИ О СЕБЕ"
  - Портрет молодой женщины с длинными волнистыми каштановыми волосами
  - На фоне размытые огни (эффект боке)
  - Размер: рекомендуется 800x1200px или больше

- **step-2.png** - Изображение для второго шага "ПОДБИРАЕМ КОМПАНИЮ"
  - Группа молодых людей за столом на открытом воздухе вечером
  - Струнные огни и лампы Эдисона
  - Размер: рекомендуется 800x1200px или больше

- **step-3.png** - Изображение для третьего шага "МЫ ВСЁ ОРГАНИЗУЕМ"
  - Две руки, держащие бокалы с белым вином в жесте тоста
  - Размытый фон с теплыми огнями
  - Размер: рекомендуется 800x1200px или больше

- **step-4.png** - Изображение для четвертого шага "ДЕНЬ X"
  - Женщина с темными волосами, держащая бокал вина и телефон
  - Улыбается, смотрит на зрителя
  - Размер: рекомендуется 800x1200px или больше

## Формат файлов

- Формат: PNG (или JPG)
- Ориентация: Портретная (вертикальная)
- Рекомендуемое разрешение: минимум 800x1200px
- Оптимизация: Рекомендуется оптимизировать изображения для веба (можно использовать инструменты вроде TinyPNG)

## Примечания

Все изображения будут автоматически использоваться в компоненте OnboardingScreen.
Пути к изображениям определены в `src/lib/images.ts`.
